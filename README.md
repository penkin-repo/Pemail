# Pemail

Компактный настольный почтовый клиент и локальный архиватор для **Яндекс.Почты** и **Gmail** на чистом **.NET Framework 4.8 (WPF)** без сторонних библиотек и без OAuth2.

Главная задача **Pemail** — хранить все письма локально в сжатом архиве с мгновенным поиском и безопасно освобождать место (ГБ) на серверах почтовых провайдеров, когда ящик приближается к лимиту.

## Возможности

- **Яндекс.Почта и Gmail (IMAP + SMTP поверх TLS)** — работа по паролю приложения без регистрации OAuth-приложений.
- **Все папки** — входящие, отправленные, черновики и пользовательские папки (с поддержкой кириллицы Modified UTF-7).
- **Сжатый локальный архив** — оригиналы писем сохраняются в `PemailData\Archive\<аккаунт>\<папка>\<год>\<месяц>\<uid>.eml.gz` (`GZipStream`). Любое письмо можно экспортировать обратно в чистый `.eml`.
- **Мастер «Очистка ГБ»** — предпросмотр старых и крупных писем, которые гарантированно сохранены локально, и безопасное удаление их с сервера (через Корзину + `EXPUNGE`) для реального освобождения квоты.
- **Цветные бейджи и превью вложений** — мини-названия прямо в списке писем и лента превью (миниатюры картинок, цветные метки: PDF — красный, Excel — зелёный, Word — синий, архивы — янтарный, картинки — фиолетовый и т.д.).
- **Быстрый локальный поиск и фильтры** — поиск по теме, отправителю, получателю, тексту письма и именам вложений; фильтры «Вложения», `>1 МБ`, «Архив», «На сервере».
- **Отправка и ответы** — `Ответить`, `Ответить всем`, `Переслать`, вложения, отправка по `Ctrl+Enter`, автосохранение и автоподсказки адресов получателей.
- **Пакетные операции** — выделение нескольких писем через `Shift` / `Ctrl` / `Ctrl+A` без чекбоксов, архивация или удаление всей пачкой.
- **Светлая и мягкая тёмная тема** — переключение в один клик с сохранением выбора.
- **Безопасность** — пароли приложений шифруются через **Windows DPAPI** (`ProtectedData`), в HTML-письмах вырезаются `<script>` и по умолчанию блокируются внешние изображения.

## Настройка аккаунтов

### Яндекс.Почта
1. В настройках Яндекс.Почты включите доступ по **IMAP** («Почтовые программы»).
2. В Яндекс ID создайте **пароль приложения** для почты.
3. В Pemail откройте **«Аккаунты» → «+ Добавить»**, выберите **Яндекс.Почта**, введите email и пароль приложения → **«Проверить вход» → «Сохранить»**.

### Gmail
1. Включите двухфакторную аутентификацию в аккаунте Google и создайте **пароль приложения**.
2. В Pemail выберите **Gmail**, введите email и 16-значный пароль приложения → **«Проверить вход» → «Сохранить»**.

## Сборка из исходников

Требуется только стандартный `.NET Framework 4.8` (встроен в Windows 10/11), внешние NuGet-пакеты не требуются:

```cmd
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe Pemail.csproj /p:Configuration=Release /v:minimal
```

Собранный файл: `bin\Release\Pemail.exe`.

## Хранение локальных данных

Все данные хранятся портативно рядом с `Pemail.exe` в папке `PemailData\`:
- `accounts.json` — настройки ящиков (пароли зашифрованы Windows DPAPI под текущего пользователя);
- `index.json` — локальный поисковый индекс писем;
- `contacts.json` — сохранённые адреса получателей для автоподсказок;
- `settings.json` — настройки интерфейса (тема);
- `Archive\` — сжатые оригиналы писем `.eml.gz`.

> Папка `PemailData\` добавлена в `.gitignore` и никогда не должна попадать в git.

## Структура проекта

```text
Pemail/
├── App.xaml / App.xaml.cs     # Ресурсы, векторные иконки, стили и старт приложения
├── app.ico                    # Иконка приложения (PM)
├── Pemail.csproj              # Проект WPF (.NET Framework 4.8, без зависимостей)
├── Models/
│   ├── AccountConfig.cs       # Модель аккаунта, пресеты Gmail/Яндекс, шифрование DPAPI
│   └── MailModels.cs          # Модели папок, писем, контактов, цветных бейджей вложений
├── Net/
│   ├── ImapClient.cs          # IMAP4rev1 поверх SslStream (LIST, UTF-7, QUOTA, FETCH, EXPUNGE, APPEND)
│   └── SmtpClientEx.cs        # SMTP поверх SslStream (465 Implicit TLS / 587 STARTTLS) + сборка MIME
├── Mime/
│   └── MimeParser.cs          # Разбор RFC 5322 / MIME / RFC 2047, кодировки, безопасный HTML
├── Storage/
│   └── ArchiveStore.cs        # Архив .eml.gz, индекс, контакты, сверка удалений с сервера
└── UI/
    ├── MainWindow.xaml(.cs)   # Главное 3-панельное окно, синхронизация, превью, пакетные действия
    ├── ComposeWindow.xaml(.cs)# Написание/ответ, Ctrl+Enter, автоподсказки адресов
    ├── CleanupWindow.xaml(.cs)# Мастер предпросмотра и освобождения места на сервере
    ├── AccountsWindow.xaml(.cs)# Управление аккаунтами и тест подключения
    └── ThemeManager.cs        # Светлая и мягкая тёмная тема (DynamicResource)
```
